Method Brand Guide
Draft v1 · for approval

One set of rules for every Method screen staff use. The black header and green rule already on Account Briefing, Carpet Care Board and Simple Proposal is the brand. This guide writes those screens down as rules, settles the leftover conflicts, and ranks the screens that need to catch up.

Built from the Oct 4–5 2026 audit: 42 screens, 30 apps, 127 captures at 1280 / 820 / 390. Looks only. No functional or structural changes. Payments and Sales Receipts are off limits.

1 · Decisions this guide makes

Yellow

One yellow: #FDCB2E

The header tag moves from #FDBC32 to #FDCB2E. The yellow buttons are Method's preset colour and are likely locked. The tag is our own HTML, so it's a one-value edit on each header.

Green

Two greens, each with one job

#7AC043 is used only for lines (the header rule, band rule and tile top). #007B4A is used only for button fills and "good" status. White text on #7AC043 is about 2.2:1, which is unreadable on a button. Website green #54B435 stays off Method screens.

Button size

One action size: Regular 14px

Large (15.75) and XLarge (19.25) are retired. XSmall (10.5) is allowed only for filter chips and inline toggles, never for a main action.

Back

One Back: silver pill, top left

It sits in the action row under the header, not beside it. That alone fixes the "offset header" on Invoice, Estimate and Field Crew lists.

Save

Save is always a button

Where Save is a blue text link (Invoice, Estimate, PO), hide the link and add a black SAVE pill wired to the same Save action. The audit already lists this as the approved fix.

Method blue

Never on purpose

#0D71C8 stays only where Method draws it and we can't change it: split buttons, grid links, checkboxes and search. Never use it in a control we build.

5 · Spacing & screen sizes

8px base. 8px between buttons, 16px between header and action row, 24px between sections. Every check below is required at all three sizes before a screen counts as done.

Desktop
1280

Header and bands run full content width. Nothing gets clipped at the right edge (Field Crew REFRESH fails this today). Grid column headers are not truncated.

Tablet
820

No field row of more than 3 inputs. Nothing runs under the right-hand activity rail. No blank gaps where a panel hides.

Mobile
390

Lists show at most 3 columns (ID, name, amount or status). The header title fits on one line, and the tag can wrap below it. BACK is present. No button label wraps mid-word.

6 · Do and don't

Do
  • Copy the header and band HTML exactly. Change only the title and tag.
  • Use CAPS on every button we build.
  • Hide a stock control that clashes and add a branded button wired to the same action.
  • Check 1280, 820 and 390 before you save the screen.
Don't
  • Use Method blue, #54B435, #FDBC32 or #1A1A1A in anything new.
  • Put a button or pill beside the header. Buttons belong in the action row below it.
  • Mix button sizes in one action row.
  • Centre band captions, or make bands narrower than the content.
  • Change fields, logic, workflows, screen names, or Payments / Sales Receipts.

Method's own chrome stays as it is: the navy left nav and mobile bar, the blue Save & Back / Batch / Share split buttons, grid links and checkboxes. That's a known ceiling, so don't spend time fighting it.
